# IDLE

Multi-agent coding IDE — understand, plan, delegate, patch, verify, and integrate.

## Development

This repository is being built from the approved design specification and implementation roadmap.

- Design: `docs/superpowers/specs/2026-08-19-multi-agent-ide-design.md`
- Implementation plan: `docs/superpowers/plans/2026-08-19-multi-agent-ide-implementation-plan.md`

V1 is Windows-first and uses a local agent runtime with Nemotron behind an LLM provider abstraction.
