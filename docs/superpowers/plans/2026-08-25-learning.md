# Durable Learning Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extract verified task outcomes into durable, bounded project lessons and retrieve them through the existing project-memory layer.

**Architecture:** Keep `ProjectLearningService` as the persistence/retrieval boundary. Add a deterministic `TaskLearningExtractor` that maps verified task outcomes to structured lessons, then integrate it with the existing task outcome recorder without allowing learning failures to affect execution.

**Tech Stack:** TypeScript, Vitest, existing JSON-backed `MemoryRepository`; no new dependency.

**Spec:** `docs/superpowers/specs/2026-08-25-learning-design.md`

## Global Constraints

- Only verified outcomes may create durable learning.
- Learning extraction is deterministic; no LLM/vector database.
- Bound learning text and never persist credentials/secrets.
- Learning failures are non-fatal to task execution.
- Reuse project-scoped `ProjectMemory` persistence and retrieval.
- Preserve confidence/source/validation metadata.
